## 🏆 Alguns resultados

- **App desktop em Electron:** reestruturei a aplicação até a produção, reduzindo o instalador de **600 MB para 85 MB (−86%)** e o tamanho instalado de **1,2 GB para 287 MB (−76%)**. Também modularizei a arquitetura (arquivo principal de ~1.200 para ~300 linhas) e implementei atualização automática.
- **Migração de legado:** reativei um cardápio web parado havia ~5 anos, que não rodava localmente, migrando de Create React App para **Next.js (App Router)**.
- **Pagamentos:** implementei pagamento com cartão (fingerprint e criptografia de dados sensíveis no front), **Pix, NuPay e PicPay**.
- **Geração em lote:** desenvolvi o front de um gerador de artes com logo e QR code personalizados para centenas a milhares de lojas.
- **Estabilidade:** monitoramento de erros com Bugsnag (sourcemaps e redução de ruído) e alertas automáticos no Slack.

## 📌 Projetos em destaque

### [Vezon](https://vezon.app): SaaS de agendamento
Produto completo com 5 aplicações: API, painel administrativo, página pública de agendamento, site institucional e app mobile.
- **Web:** React + Vite, TanStack (Router, Query, Table, Form), shadcn/ui, React Hook Form, Zod, Zustand e Next.js
- **Mobile:** React Native + Expo (Expo Router, NativeWind) com notificações push via Firebase
- **Back-end:** NestJS, Prisma, PostgreSQL (Supabase), Redis, Docker, Swagger e testes com Vitest
- **Integrações:** WhatsApp Cloud API, Resend e cobrança recorrente via Asaas

### [StockFlow Manager](https://github.com/allessandrogomes/stockflow-manager): gestão de garantias
Sistema desktop feito para a Bonfim Baterias LTDA (Grupo Moura). Controla prazos de garantia e o estoque de baterias de empréstimo, e automatiza o contato com clientes atrasados via WhatsApp.
`React` `Redux` `Electron` `MUI` `Formik` `Yup`

### [Neto Baterias](https://github.com/allessandrogomes/netobaterias): site institucional
Site para revendedor de baterias em Juazeiro-BA e Petrolina-PE, em Next.js com otimização de SEO local.
`Next.js` `TypeScript` `SEO`

### [MangoMan](https://mangoman.com.br): site para exportadora de frutas
Site institucional de uma exportadora de mangas, cocos e limões do Vale do São Francisco. Tem conteúdo em 4 idiomas (inglês, português, espanhol e francês), formulário de cotação, mapa integrado, botão de WhatsApp e SEO voltado ao mercado internacional (metadados Open Graph, Twitter Cards e URL canônica).
`Next.js` `Tailwind CSS` `i18n` `SEO`
